# Marc John Granados — System Administrator Career Portfolio

Responsive static website for the academic project **“Web-Based System Administrator Career Portfolio: Certifications and Professional Development.”** Styled with a violet and lavender theme and interactive UI.

## Simplified project structure
- `index.html` — website content and structure
- `style.css` — violet theme, responsive layout, and effects
- `script.js` — mobile navigation, filters, scroll progress, reveal animations, and counters
- `profile.svg` — illustrated profile avatar placeholder

## Run locally
Extract the folder and open `index.html` in a browser, or run it through VS Code Live Server. No database, login, or backend is required.

Certification links are official sources: CompTIA A+, CompTIA Network+, RHCSA, and CompTIA Security+. Learning links include Microsoft Learn, Red Hat documentation, and Cisco Skills for All.
